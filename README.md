Website chính thức & Cổng thông tin của **CLB Tin học ITUP**. Tích hợp **Trợ lý AI Chatbot Google Gemini**, đọc tài liệu dạng Flip-book và quản lý sự kiện/thành viên.

---

## ✨ Tính Năng Nổi Bật

- 🤖 **AI Chatbot Gemini:** Hỏi đáp tư vấn thành viên CLB về lịch sinh hoạt, lập trình.
- 📖 **Flip-Book Reader:** Đọc tài liệu, slide bài giảng dạng lật trang sách chân thực.
- 📅 **Quản Lý Sự Kiện & Bài Viết:** Đăng ký tham gia workshop, tin tức hoạt động CLB.

```bash
git clone https://github.com/nguyenhuynhdt37/ITUP_SOURCE.git
cd ITUP_SOURCE
npm install
npm run dev
```
