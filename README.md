Cổng thông tin chính thức của **CLB Tin học ITUP**. Tích hợp **Trợ lý AI Chatbot Google Gemini**, trình đọc tài liệu Flip-book lật trang và quản lý sự kiện.

---

## ✨ Tính Năng Nổi Bật

- 🤖 **AI Chatbot Gemini:** Trả lời tự động câu hỏi về lịch học, hướng dẫn lập trình cho thành viên.
- 📖 **Flip-Book Document Reader:** Xem bài giảng và tài liệu môn học dưới dạng lật trang sách chân thực.

```bash
git clone https://github.com/nguyenhuynhdt37/ITUP_SOURCE.git
cd ITUP_SOURCE
npm install
npm run dev
```
